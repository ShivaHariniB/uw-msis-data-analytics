# UW Foster MSIS 502B: Business Data Analysis

This repository contains academic coursework, data analytics pipelines, and statistical modeling implementations completed during the **MSIS 502B: Business Data Analysis** course (Summer 2026) within the Master of Science in Information Systems program at the University of Washington, Foster School of Business.

The core focus of this track is translating complex datasets into actionable strategic advantages, utilizing Python data science ecosystems alongside modern Generative AI acceleration frameworks.

---

## 🎯 Key Learning Objectives

- **Problem Frameworks:** Formulating structured data analysis plans, executing complex computations, and interpreting analytical results to guide executive actions.
- **Statistical Application:** Gaining hands-on engineering experience applying statistical modeling techniques to real-world business challenges.
- **AI-Augmented Workflows:** Integrating Generative AI frameworks into the data analyst workflow to accelerate scripting and processing tasks while ensuring analytical precision, reproducibility, and responsibility.

---

## 🛠️ Core Technologies & Methodologies

- **Programming Languages:** Python 3.x
- **Analytical Frameworks:** Principles of Regression Analysis, Classification and Regression Trees, and alternative Tree-based machine learning methods.
- **Core Practices:** Data Representation, Exploratory Data Visualization, and Analytics-Driven Stakeholder Negotiation.

## 🗓️ Technical Course Curriculum

The curriculum spans from initial syntax configurations to production-ready predictive structures:

- **Foundations:** Python syntax basics and specialized Python libraries engineered for data science applications.
- **Exploration:** High-impact data representation principles and programmatic visualization techniques.
- **Modeling:** Statistical foundations of regression analyses alongside Classification and Regression Tree structures.
- **Advanced Analytics:** Alternative tree-based ensemble methods, guest lectures from industry experts, and analytical stakeholder communication.
